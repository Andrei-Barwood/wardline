# Código de Conducta de Wardline

Como participantes, colaboradores y mantenedores en el laboratorio Wardline, nos comprometemos a fomentar una comunidad abierta, acogedora y libre de acoso para todos.

## Nuestros Estándares

Ejemplos de comportamiento positivo incluyen:
* Utilizar un lenguaje acogedor, inclusivo y respetuoso.
* Ser respetuoso ante puntos de vista diferentes.
* Aceptar críticas constructivas con gracia.
* Enfocarse en qué es lo mejor para el proyecto educativo general.

Ejemplos de comportamiento inaceptable incluyen:
* El uso de lenguaje sexualizado o comentarios inapropiados.
* Ataques personales, insultos o comentarios despectivos (trolling).
* Acoso público o privado.
* Fomentar el uso de este proyecto con fines ofensivos o de ataque real a infraestructuras en Internet.
* Publicar información privada de terceros sin permiso explícito.

## Aplicación

Los mantenedores del proyecto tienen el derecho y la responsabilidad de eliminar, editar o rechazar comentarios, commits, código, ediciones de la wiki, issues y otras contribuciones que no estén alineadas con este Código de Conducta.
Cualquier abuso o comportamiento inaceptable puede ser reportado al equipo responsable del proyecto y será investigado de manera justa y confidencial.
